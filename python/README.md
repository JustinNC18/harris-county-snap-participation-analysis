# Python Scripts

These scripts automate retrieval and preparation of public datasets used in this project.

## Scripts

### 01_pull_c17002.py

Pulls ACS poverty data.

### 02_pull_s2201.py

Pulls ACS SNAP household data.

### 03_pull_b25010.py

Pulls ACS average household size data.

### 04_pull_hud_crosswalk.py

Retrieves HUD ZIP crosswalk data.

### 05_create_county_lookup.py

Creates lookup tables for ZIP and county analysis.
